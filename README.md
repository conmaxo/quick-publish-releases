# Quick Publish for macOS

Public downloads and automatic-update feed for Quick Publish (Apple Silicon).
This repository contains release artifacts only. The application source is private.

## Updates

Signed releases appear on the Releases page. Install the signed app once, then use
Settings → Application updates to check, download, and restart to install.
The app also checks for new stable releases at startup and every six hours.

[Download Quick Publish 0.0.2](https://github.com/conmaxo/quick-publish-releases/releases/tag/v0.0.2).
This release is Developer ID signed and notarized by Apple. Requires macOS 13+
on Apple Silicon. Open the DMG and drag Quick Publish into Applications, replacing
the previous local build once to enable future in-app updates.
